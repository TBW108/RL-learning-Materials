# RL-learning-Materials

A curated collection of materials for learning Reinforcement Learning (RL), including books, papers, and algorithm implementations.

## Repository Structure

```
RL-learning-Materials/
├── Books/          # Recommended textbooks and reading materials
├── Papers/         # Key research papers in RL
└── Algorithms/     # Code implementations of RL algorithms
```

## Contents

### 📚 [Books](./Books/README.md)
Foundational and advanced textbooks covering RL theory and practice.

### 📄 [Papers](./Papers/README.md)
Landmark and recent research papers in Reinforcement Learning.

### 💻 [Algorithms](./Algorithms/README.md)
Python implementations of classic and modern RL algorithms, including:
- Dynamic Programming (Value Iteration, Policy Iteration)
- Model-Free Prediction & Control (TD, Q-Learning, SARSA)
- Policy Gradient Methods (REINFORCE, Actor-Critic)
- Deep RL (DQN, PPO)

## Getting Started

### Prerequisites
- Python 3.8+
- [NumPy](https://numpy.org/)
- [Gymnasium](https://gymnasium.farama.org/) (for running algorithm examples)
- [PyTorch](https://pytorch.org/) (for deep RL algorithms)

Install dependencies:
```bash
pip install numpy gymnasium torch
```
