# Books

A curated list of textbooks and reading materials for learning Reinforcement Learning.

## Foundational Textbooks

| Title | Authors | Year | Link |
|-------|---------|------|------|
| Reinforcement Learning: An Introduction (2nd ed.) | Sutton & Barto | 2018 | [Free PDF](http://incompleteideas.net/book/the-book-2nd.html) |
| Algorithms for Reinforcement Learning | Szepesvári | 2010 | [Free PDF](https://sites.ualberta.ca/~szepesva/rlbook.html) |
| Deep Reinforcement Learning Hands-On | Maxim Lapan | 2020 | [Packt](https://www.packtpub.com/product/deep-reinforcement-learning-hands-on-second-edition/9781838826994) |
